## 核心交互

三版均在真实浏览器完成：

- 日期切换；地图选择博物馆更新详情；列表选择人民公园同步地图选中。
- 点击已知交通打开比较；未知交通保持显式“未查询”，不会虚构查询完成。
- AI 候选只预览时，原行程不改变；确认后第一天地点改变、相关交通变为待查询。
- 撤销后人民公园回到第一天、博物馆回到第二天。
- Escape 关闭比较弹层；交互全程没有页面脚本异常。
- 对比页点击 C 后实际切换对应 iframe。

A 对第三天新增地点保留待安排，不自动占返程时段；B、C 展示建议时段，并明确占用返程留白、需要复核。这是草图对“确认候选”的两种表达，不构成已经确定的产品行为。

## 复现

已安装全局 Puppeteer 的 Windows 环境，从项目根目录执行：

```powershell
node docs/design/desktop/research-2026-10/verify-sketches.cjs
node docs/design/desktop/research-2026-10/check-interactions.cjs
```

如 Puppeteer 位于其他目录，设置 `PUPPETEER_PATH` 指向其模块目录。脚本只打开当前研究目录中的草图；截图浏览器使用本机 Edge。两个脚本均已运行通过。
