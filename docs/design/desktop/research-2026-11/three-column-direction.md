# 三栏工作台方向研究（2026-11 · 未实施）

> 起因：用户对桌面布局的三条指认 —— ①「整体布局从中间劈开左右，中间栏不能左右调整」；
> ②「AI 改行程页面和左边的每一个条目的详情页面都是覆盖在地图上面，没那么合适」；③「整体的布局都比较别扭」。
> 结论：三条是同一结构性根因，建议做一次**结构性**改版；先出方向稿确认审美，再动实现。

## 1. 根因诊断（对照 `Workspace.tsx` 现状）

现行桌面（≥1024，M31）为 `58% | 42%` 两栏，右侧 42% 是**交换槽**：
地图、地点详情、交通比较、当天安排、AI 对话、离线管理轮流占据同一块区域——
`fullPanel` 打开时地图整块 `hidden`（`Workspace.tsx:69`），点地点时地图被压到 55%（split）。

三个主角（行程文档 / 地图 / AI）只有两个座位，永远有一个被挤走；
被挤走的恰恰常是地图——而 AI 修改路线时地图该闪烁、该 panTo，是它最有用的时刻。

## 2. 方向：全幅底图 + 浮层侧栏（2026-11-15 依用户方向升级）

```
│ 日期列(底) │ 行程(浮层,可拖可收) │ —— 全幅地图常驻底图 —— │ AI 面板(浮层,右缘锚定) │
```

- **地图是背景底图**：全幅常驻、永不 resize，侧栏是浮起的一层（阴影）盖在上面——
  调整/收起任何侧栏都「不会再影响到地图」，pin 与路线不会因布局变化跳动（用户原话）；
- **现有 aux 槽语义原样搬到右栏**（place/leg/ai/map/offline 五槽与草稿保留、单实例挂载不变）；
- **行程↔地图分割线只调整行程列宽度**，中段挂收起角标；收起后只剩贴边中段一个凸出的半圆（不留长条）；
- 面板标题从「返回地图」改为「收起面板」；AI 面板不设展开角标，开关只靠顶栏按钮（用户方向）；
- Leaflet 瓦片 pane 自带 z-index 200+，浮层架构下地图容器必须 `isolation:isolate`（正式版 `.dw-map` 已有）；
- 地图角标（图例/标题 chip）按「可见区域」定位（left = 日期列+行程列宽，right = 面板宽）；
- <1024 紧凑态（底部抽屉）完全不动。
