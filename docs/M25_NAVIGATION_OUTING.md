用户于 2026-09-30 确认「验收登入我已经完成了，目前可以用」，并要求「提交一下，完成本阶段」。本阶段按此验收确认以本地提交收尾。

## 实现范围

- 地点卡、酒店卡、地图气泡均可打开「去这里」导航选项；高德／百度偏好在本机保存。
- 提供步行、公交、驾车；当前阶段不计算耗时、费用或到达时间，实际结果交给地图软件。
- 高德链接只传目的地，移动端由高德确定当前位置；百度移动端传 `我的位置` 作为起点，实际定位由外部地图处理。
- 百度 Android 网页使用 `bdapp://map/direction`，iOS 使用 `baidumap://map/direction`，按各平台官方网页示例区分协议。
- 百度桌面网页先打开目的地标记，再由用户选择起点。所有平台均保留网页版与复制地点信息。
- 「从上一计划点比较路线」独立展示，起点不是实际位置；上一点未核验时不提供比较入口。
- 手机和桌面均可切换规划／出行视图；出行视图展示当天、下一站、到达和完成状态、当天清单。
- 打开导航不更改到达／完成状态。误标完成可恢复；当天结束可切换下一天。
- 新生成／导入行程获得独立本地 session；返回首页再进入、刷新恢复同一行程的当天与进度。
- 出行状态不写 route JSON、不调用 `mutate`，不占路线撤销帧。导出不会携带个人出行进度。
- 导出 HTML 同步单地点导航；缺坐标的地点／酒店保留在清单，隐藏无效 pin，允许按名称搜索。
- Leaflet 脚本未能加载时，导出仍显示可导航的行程清单。此能力不等于网站 PWA 离线安装（M28）。

## 数据与安全边界

路线契约未增加字段。`shared/navigation.js` 是网页与导出的共同导航链接生成器。
高德采用经度、纬度；百度采用纬度、经度并显式传 `coord_type=gcj02`；不重复转换 route 坐标。
名称中的 URL 特殊字符经 `URLSearchParams` 编码；协议内分隔符 `,`／`|` 在坐标标签中替换为空格，名称搜索保留原文。

| 坐标条件 | 默认动作 |
| --- | --- |
| 用户确认／记忆真值，或高德 high | 使用保存点位 |
| 模型／搜索／未知来源、low、已有「坐标待确认」标注 | 按名称搜索；明确勾选已核对后可用保存坐标 |
| 城市中心、mock、none、缺失、零值、非有限数或超出经纬度范围 | 仅名称搜索，不能把占位坐标勾选成准确点位 |

目前没有核实的景区入口字段，界面明确说明使用保存地点标记，出入口需在地图中核对。
没有精确街道地址时，备用操作称「复制地点信息」，不把地点名或攻略备注假称地址。

localStorage：

- `itertrip:trip-session`：当前行程本地身份；不发给服务器。
- `itertrip:outing:<session>`：`day`、`mode`、`arrived[]`、`completed[]`。
- `itertrip:navigation-map`：`amap`／`baidu`。

唯一地点按名称、坐标、地点／酒店类型识别，调整顺序仍保留进度；改名／改坐标需重新确认。
重复地点按出现位置与行程结构／时段上下文区分；结构或时段变化会保守地失效其旧进度，避免把完成状态转给另一站。
同一家酒店按每天的入住分别记录。正式稳定 ID 留在 M26；不把数组下标当成跨修改的可靠地点身份。
存储失败时出行视图明确提示进度仅保留在当前页面。

导出对地名、备注、报价文本和告警进行 HTML 转义；内联 JSON 转义 `<`；预订链接只允许 HTTP(S)。
导出后的再次导出使用函数替换，含 `$&` 等字符的地名不会被当成模板替换语法。
容器镜像新增复制 `shared/`，保证后端导出能读取共用脚本。

## 回归验收参考

测试样本由 `_check_m25.py` 写到 `frontend/test-artifacts/m25/`，均为公开景点或明确标注的测试占位。
在可从设备访问的测试网站导入 `route.json`，或在支持执行脚本的浏览器中打开 `export.html`。
手机文件预览可能不执行 JavaScript，需记录实际打开方式，不把文件预览失败误记成 Safari 网页测试。

1. 记录系统、浏览器及地图 App 版本；检查 375／390px 手机宽度和桌面宽度，长名称、短屏和横屏不遮挡导航。
2. 武侯祠分别选高德／百度、步行／公交／驾车，核对目的地落点与 App 实际定位的起点。
3. 在锦里（模型坐标）默认搜索；在城市中心占位／未定位小店仅搜索，不能直接导航到占位点。
4. 从导航返回网站，确认未自动到达；手动到达、完成后刷新，恢复当天／进度；恢复未完成后下一站正确。
5. 酒店卡、地图气泡、导出 HTML 都能打开单地点导航；无 App 或限制唤起时网页版／复制信息可继续。
6. 键盘进入导航选项，焦点可见，Esc 关闭后回到触发按钮；触摸操作不受拖拽排序或底部工具栏干扰。
7. 后续回归时记录各平台结果与失败情况，修复问题后按仓库规范本地提交。

以上步骤保留供后续版本回归使用。M25 已按用户验收确认关闭；下一阶段为 M26 独立交通段与真实耗时，本次只收尾 M25。

## 官方接口依据

- [高德路径规划 URI](https://lbs.amap.com/api/uri-api/guide/travel/route)：省略移动端起点、经纬度顺序、方式与唤起限制。
- [高德名称搜索 URI](https://developer.amap.com/api/uri-api/guide/search/search)：无可靠坐标时按名称／城市搜索。
- [百度 Web URI](https://lbsyun.baidu.com/docs/webapi?title=mapadjustment/uri/web)：网页标记／名称搜索／按上一计划点比较。
- [百度 iOS URI](https://lbs.baidu.com/docs/webapi?title=mapadjustment/uri/ios)：`我的位置` 起点、坐标系、方式与 App 协议。
- [百度 Android URI](https://lbs.baidu.com/docs/webapi?title=mapadjustment/uri/andriod)：网页示例使用 `bdapp://`；与原生 Android Intent 示例中的 `baidumap://` 区分。官方路径拼作 `andriod`。
