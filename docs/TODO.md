## 1. 记忆档案 id（tid）的可携带性：导出 / 导入

### 现状

| 事实 | 位置 |
|---|---|
| tid 由 `crypto.randomUUID()` 生成，**只存**在 `localStorage['itertrip:tid']` | `frontend/src/lib/memory.ts` |
| 每次请求带 `X-Traveler-Id` 头，服务端按它归属/隔离记忆 | `frontend/src/lib/memory.ts` 的 `memoryHeaders()` |
| 服务端唯一的隔离维度就是 `chunks.traveler_id`（无账号、无鉴权、无校验） | `backend/engine/memory_store.py` |
| 三个记忆端点都只认这个头；清空只清当前 tid | `backend/api/memory.py` |

### 影响

清站点数据 / 换浏览器 / 无痕模式 / 换设备 → 生成新 tid → **服务端旧行变成孤儿**：
界面永远看不到，也不会被清（`DELETE /api/memory/all` 只作用于当前 tid）。
上云之后（M16 那台机器）更刺眼：**用户的攻略原文躺在服务器磁盘上，用户自己却没有任何入口找回来**。

### 方案候选

- **A（推荐）本地导出 / 导入 tid**：设置面板「🧠 旅行记忆」区加两个动作 ——
  「导出档案 id」（显示可复制的串）与「导入档案 id」（粘贴 → 校验格式 → 写入 localStorage → 立刻拉一次
  `/api/memory/stats` 显示条数，让用户当场看到「记忆回来了」）。
  成本：`memory.ts` +2 个函数、`SettingsPanel.tsx` +1 个折叠区、**0 后端改动**。
- **B 服务端「口令取回」**：不做。服务端没有鉴权，真做就是自己发明一套弱口令协议，
  还会给用户「本项目有账号体系」的错觉。
- **C 真正的账号体系 / 云同步**：`DESIGN.md §8` 明确不做。

### 判定标准（可验收）

1. 导出得到可复制的 36 字符串；
2. 在另一个浏览器导入后，`/api/memory/stats` 立刻显示原档案的条数（实测 ≥1 条）；
3. 导入前有明确覆盖警告（会替换当前档案 id，**不可回滚**）；
4. `DELETE /api/memory/all` 语义不变（仍然只清当前 tid）；
5. 导出文案写明「这串等于你记忆库的钥匙，别公开分享」。

### 风险 / 边界

tid 本身就是 bearer 凭据（拿到即可读该档案，服务端不校验来源）；
导出功能必须把这点写在用户看得见的地方。本项**不解决**服务端被拖库，也**不做**跨设备自动同步（那属于账号体系）。

## 2. 静默自动中断的策略复核（`PING_ABORT_MS`）

### 现状

`frontend/src/lib/streamWatch.ts` 的 `shouldAutoAbort(idleMs, sawPing)`：**只有本轮收到过 ping**
才可能在「静默 60s」时自动 abort；abort 后这一轮被标成「服务端长时间没有响应，已自动中断。」
（`useChatStream` 的 `onInterrupt("watchdog")`）。设计初衷是掐掉真死的连接 ——
旧后端没有心跳，则**永不**自动中断（`sawPing` 门控）。

### 争议

客户端看「活得很慢」和「已经死了」是同一件事。支持现状的算术很硬：心跳每 2s 一次，
静默 60s = **连续丢 30 次心跳**，心脏还在跳的话基本不可能；
反方场景是弱网 / 中间层偶发缓冲，用户可能被误停一轮已经跑了几十秒的请求。

### 方案候选

- **A（现状）** 60s + sawPing 门控，自动中断；
- **B** 只告警不自动停：把 60s 降级为「红色告警 + 强调停止键」，代价是真断连时界面会一直转，得用户自己点；
- **C** 分级：仅当本轮**从未产出任何 delta/thinking**（纯等待首字）时才允许自动中断；已经出过字的一轮交给人决定；
- **D** 阈值拉长到 120s。

### 建议

先按 A 用一段时间收集真实反馈；若真遇到误停，**优先上 C**（比 B 少妥协：早期纯等待自动收尾，已出字交给人）。

### 判定标准

1. 真断连（拔网线 / kill 掉 uvicorn）时：≤15s 出现红色告警、≤60s 收尾且文案说明原因；
2. 无思考链的慢模型连续 100s 慢速输出**不被误停**；
3. 旧后端（无 ping）永不自动中断 —— 已有回归断言 `node src/lib/stream.check.ts` 的「没心跳 + 10min → 不中断」。
