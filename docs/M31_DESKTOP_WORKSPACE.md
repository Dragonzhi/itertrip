## 交付

桌面宽度 ≥1024px 使用温暖的旅行工作台。顶部包含日期、撤销／重做、明确的 AI 入口、导出与更多工具；当天时间线显示到达／离开、停留、交通段、已知小计和未知条件。详细来源、预约、备注、酒店报价进入辅助区。

≥1280px 为 360px 行程 + 实际地图区域 + 按需 320px 辅助区；1024–1279px 辅助内容与 320px 行程栏切换。地图不会被两块浮动侧栏覆盖。宽度更小的原有布局、首页／独立对话页和导出模板布局保持原行为。

先形成 [设计规范](design/desktop/DESIGN.md)、[决策记录](design/desktop/design-contract.md)、[实现交接](design/desktop/implementation-handoff.md) 和 [五种场景交互草稿](design/desktop/example.html)，再实现桌面组件。草稿地图与时间是示意数据，不是旅行信息。

## 实现与兼容

- `Plan` 保留业务处理与共享历史栈；桌面日期／辅助区／稳定选择为视图状态，不写行程。移动或撤销后按地点 ID 解析当前索引，删除则关闭详情；交通按起终点 ID 解析。
- `Timeline` 增加可选桌面模式；`WeatherPanel` 增加可选受控日期，切天取消旧查询／预览，旧响应不得写入。AI 与天气各只挂载一份，切换辅助内容保留状态；关闭 AI 区不会停止流，停止使用原独立按钮。
- 地图用实际容器与 ResizeObserver 更新尺寸，观察器卸载清理；展开辅助区／编辑后不重置桌面缩放，切天或主动聚焦调整视野。
- 地点／酒店／预约编辑复用现有表单、校验和保存。地图选点提示置于地图内，支持取消；拖拽、上下移动和跨天选择都使用原移动处理与撤销。
- 后端 API、RouteJSON、localStorage 和导出契约未改；未增加 UI 框架、在线字体或运行时依赖。
- 旧天气测试依赖 2026-10-03 的静态未来场景，随日期推进已经过期。新增仅供测试使用的日期移位工具，在内存中生成未来场景和新读取时间；保留原风险断言和生产时效检查。
